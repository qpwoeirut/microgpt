# microgpt

A rewrite of Karpathy's [microgpt](https://karpathy.github.io/2026/02/12/microgpt/) for personal learning, trained on a [list of cities with population over 20,000](https://www.census.gov/data/tables/time-series/demo/popest/2020s-total-cities-and-towns.html) from the US Census Bureau.

The original baseline is under `baseline/`. My rewrite is at the top level of the repository.
